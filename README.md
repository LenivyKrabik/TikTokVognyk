# TikTokVognyk

TikTokVognyk is scraper, that allows to sustain your strike in TikTok conversations without actually openning up app or website. For once peace of mind. Brainrot free.
Currently supports only up to 4 friend on first video share and 6 on messages. This is easy fix if I wanted to make it
## Use:
### Prerequisits:
1. Install playwright library and chromium for it:
```
pip install playwright
playwright install
```
2. Launch setup.py 
3. There log in into your account. You have 5 minutes for it. The best my lazy self can do
4. Pin all of chats you want to mantain

### Use:
Run main.py and wait a little.
### Change settings:
Run setup.py again (you can close browser, if you don't need to re-login)
